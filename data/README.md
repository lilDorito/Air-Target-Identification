# data/

This folder is **gitignored**. Only this README is committed.

Put the dataset here as `data/targets.csv`. See [`../docs/DATA_COLLECTION_NOTICE.md`](../docs/DATA_COLLECTION_NOTICE.md).

## Expected schema (one row per target)

| Column | Type | Notes |
|---|---|---|
| `name`, `manufacturer`, `callsign`, `family`, `country` | text | identity: never model inputs |
| `type`, `role` | text | labels |
| `ua_war`, `status` | text | context: never inputs |
| `speed_min_kmh`, `speed_cruise_kmh`, `speed_max_kmh` | number | km/h |
| `alt_min_m`, `alt_max_m` | number | metres |
| `climb_max_ms` | number | m/s |
| `turn_rate_max_dps` | number | degrees per second |
| `rcs_min_m2`, `rcs_max_m2` | number | m² |
| `engine_type` | text | category |
| `engine_count` | number | |
| `afterburner` | yes / no | |
| `ir_category` | low / medium / high / very high | ordinal |
| `flight_profile` | text | **excluded from inputs** |
| `length_m`, `wingspan_m`, `mtow_kg`, `first_flight` | number | |
| `sources`, `estimated_fields`, `notes` | text | provenance: never inputs |

Sampled observations generated by `src/sampling.py` are written here too, so they also stay local.
